# Gill Wiki

Static documentation site for Gill / SeL4.

## GitHub Pages

1. Put these files in a repository or a `docs/` directory.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the branch containing the site and the root (or `/docs`).
5. Save.

The site uses plain HTML, CSS, and a tiny JavaScript search/filter script. No framework or build step is required.
