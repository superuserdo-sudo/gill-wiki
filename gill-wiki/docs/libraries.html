Libraries

Gill will use libraries to keep reusable functionality separate from individual programs.

Possible library areas

  • Core I/O.
  • String and memory helpers.
  • System interfaces.
  • GCU shared functionality.

Library names and APIs should be treated as provisional until implemented.
