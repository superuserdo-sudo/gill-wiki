Goals

Gill aims to explore how much useful system functionality can be built while keeping the core understandable and lightweight.

Core goals

  • Keep core components small.
  • Prefer understandable system design over unnecessary complexity.
  • Build lightweight command-line utilities.
  • Separate system responsibilities into focused components.
  • Use low-level software where it provides meaningful control.
  • Document the project clearly enough that its internals can be studied.

Non-goals

Gill does not currently promise compatibility with every existing Unix/POSIX interface, desktop environment, or application ecosystem. Compatibility can be added where it makes sense later.
