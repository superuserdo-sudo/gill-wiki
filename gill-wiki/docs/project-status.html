Project Status

Gill is currently an experimental project.

Current

  • Gill / SeL4 is the project's core system direction.
  • GCU is being developed as a collection of small C++ utilities.
  • Current GCU development version: v1.pre-dev.0.
  • The repository and documentation are still evolving.

Planned

  • More complete system components.
  • A defined build and boot pipeline.
  • More GCU utilities and documentation.
  • Clearer system interfaces and library boundaries.
Important: planned architecture in this wiki should not be interpreted as implemented functionality.
